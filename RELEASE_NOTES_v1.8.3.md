# K2E Local v1.8.3 — Vertical Energy Bars

## Changed
- Converted the device energy bar chart from horizontal bars to vertical columns that grow upward.
- Kept the chart locked to the donut-sized viewport so switching views does not resize the page.
- Added 18% headroom above the highest-energy device so the leading column does not touch the top.
- Added horizontal containment for larger device lists without increasing chart height.
- Preserved sorting from highest to lowest energy use, theme contrast, tooltips, and local data compatibility.

## Scope
This release changes chart presentation only. Energy calculations and saved data are unchanged.
