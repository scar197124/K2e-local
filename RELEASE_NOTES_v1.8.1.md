# K2E Local v1.8.1 — Guided Comparison Refinement

## Purpose
This release deliberately avoids feature expansion. It makes scenario comparison easier to understand, safer to use, and more honest about uncertainty.

## Improvements
- Renamed the advanced comparison area to **Compare a Change**.
- Added a four-step guide: build the current setup, duplicate it, change one or two inputs, then compare.
- Added context-sensitive next-step guidance.
- Replaced technical baseline/comparison wording with current setup/proposed change language.
- Prevented comparing a scenario against itself.
- Strengthened wording around annualized figures, confidence, seasonal variation, rates, taxes, and fixed utility charges.
- Kept comparison tools hidden in Simple Mode.
- Preserved the existing local workspace and browser data schema.

## Product boundary
K2E Local comparisons are planning estimates. They are designed to show direction and approximate scale, not guarantee savings or predict an exact utility bill.
