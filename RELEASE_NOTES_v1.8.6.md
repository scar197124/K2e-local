# K2E Local v1.8.6 — Slim Vertical Energy Bars

- Reduced visible energy-column width by approximately 50%.
- Anchored columns and labels to the lower portion of the fixed chart card.
- Increased usable vertical plotting room while retaining 18% headroom above the largest value.
- Changed device slots to flexible responsive widths so a typical three-bedroom household set fits without horizontal scrolling.
- Horizontal scrolling remains available only when the device count exceeds the available width.
- Preserved calculations, themes, saved data, and the donut-height chart container.
