# K2E Local v1.8.2

## Stable chart switching

- Locked the chart viewport to the donut chart height.
- Bar and donut views now occupy the same fixed vertical space.
- Removed dynamic bar-stage height growth when device counts change.
- Kept internal vertical scrolling available for dense horizontal bar lists.
- Added responsive fixed heights for desktop, mobile, and narrow phones.

This maintenance release preserves the existing data model and calculations.
