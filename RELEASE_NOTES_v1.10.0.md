# K2E Local v1.10.0 — Action Plan and Report

## Added
- Ranked three-step household action plan generated locally from the active device model.
- Clear impact, effort, and confidence labels for each recommendation.
- Conservative modeled opportunity ranges without guaranteed-savings claims.
- Printable report preview with browser Print / Save PDF support.
- Downloadable standalone HTML energy report for offline archiving and sharing.
- Report sections for household totals, estimate quality, ranked actions, device estimates, assumptions, and uncertainty.

## Preserved
- Local-first and offline operation.
- Existing homes, scenarios, calculations, themes, charts, and saved data.
- No external AI, account, tracking, or cloud requirement.
