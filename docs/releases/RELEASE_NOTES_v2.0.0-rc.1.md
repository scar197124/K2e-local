# K2E Local v2.0.0-rc.1

## Trust and import reliability

- Added an always-visible electricity-rate source label: manual, typical planning rate, or utility import.
- Added a compact post-import summary with the filename, effective rate, calculation basis, replace action, and clear action.
- Added a plain-language explanation of estimate inputs and common bill items that may not be included.
- Added a 5 MB utility-file limit, empty-file rejection, and extension validation for XML, CSV, and JSON.
- Improved import status announcements and keyboard focus visibility.
- Archived historical release notes under `docs/releases/` and older social-preview assets under `assets/archive/`.
- Updated release metadata and the offline cache identity.

## Release-candidate focus

This build is feature-complete for the 2.0 stable line. Remaining work should focus on real-provider fixture testing, mobile verification, accessibility review, and wording corrections rather than adding new Simple Mode features.
