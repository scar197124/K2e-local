# K2E Local v2.0.0-rc.5

## Compact Stable Energy Workspace

This release tightens the unified Explore your energy workspace so lighter tools no longer sit inside an oversized card while preserving stable switching between tools.

### Changes

- Reduced the shared desktop workspace height from 620px to 480px.
- Reduced the bounded mobile workspace height to 500px.
- Device Controls and Reports continue to scroll internally when their content exceeds the shared card height.
- Smart Home, AI Advisor, Rates & Schedules, and Reports retain the same outer height, preventing page jumps when switching tools.
- No changes to household calculations, device presets, or the locked guided setup flow.

### Validation

- Release metadata synchronized to v2.0.0-rc.5.
- Service-worker cache rotated.
- JavaScript syntax and release validation checked before packaging.
