# K2E Local v2.0.0-rc.45

Release date: 2026-08-30

## What changed

- Consolidated navigation labels and action wording across existing K2E tools.
- Added a shared-context cue to key workspaces so handoffs feel connected rather than isolated.
- Standardized badge density, card rhythm, and button sizing.
- Tightened mobile spacing and primary-action stacking.
- Preserved all existing household, goal, timeline, forecast, measurement, and mission behavior.

## Scope

This is a UI/consistency release only. It adds no new product layer and no external service dependency.
