# K2E Local v2.0.0-rc.44

Release date: 2026-08-30

## Goal Mode

- Adds a local monthly bill-savings target and timeframe.
- Stores the modeled baseline at the time the goal is created so later model changes can show progress.
- Builds a conservative ranked device plan using current modeled or observed monthly use.
- Keeps CT/imported/smart-device observations separate from the original device setup.
- Sends the first recommended action into What-If Lab.
- Saves the ranked goal path into Savings Missions on request.
- Adds goal context to Home Pulse and the deterministic local Advisor.

## Safety and scope

Goal Mode is planning-only. It does not control devices, change saved device settings, call external AI, or guarantee utility-bill savings.
