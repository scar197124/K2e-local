# K2E Local v2.0.0-rc.22

Release date: 2026-08-08

## What changed

- Refined the main application hero so the entry point reads **Your plan starts here.**
- Increased the visibility of **Easy by design** slightly for better hierarchy.
- Added a cleaner decorative hero mark that uses K2E's existing interface palette rather than introducing new colors.
- The hero mark combines a house, a lock-as-door, and an external lightning bolt to communicate **home**, **privacy**, and **incoming energy**.
- Kept the hero enhancement lightweight and responsive so mobile layouts remain stable.

## Notes

This release is a visual polish release only. It does not alter K2E's planning logic, Smart Home trust model, or AI Advisor behavior.
