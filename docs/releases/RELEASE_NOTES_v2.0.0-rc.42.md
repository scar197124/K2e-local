# K2E Local v2.0.0-rc.42

Release date: 2026-08-30

## Smart Energy Hub + Measurement Intelligence

- Adds a sharper Smart Energy Hub at the top of Smart Home.
- Adds optional local CT clamp / energy monitor, imported reading, and smart-device report context per device.
- Keeps original watts/runtime inputs intact and compares modeled vs observed monthly kWh.
- Adds source and confidence labels so K2E can distinguish estimated, measured, imported, and planning-only smart-device context.
- Adds direct What-If and device-review handoffs.
- Adds Advisor measurement context without claiming a live hardware or cloud connection.

No external hardware connection, account, cloud sync, or remote control is introduced in this release.
