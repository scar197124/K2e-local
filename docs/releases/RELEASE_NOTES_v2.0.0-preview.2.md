# K2E Local v2.0.0-preview.2

A full interface rebuild.

- Replaces the old 12,000-line app screen with a new self-contained UI.
- Adds a true three-step Simple Mode.
- Adds a separate Advanced Mode with editable device data.
- Simple and Advanced modes share the same local household state.
- Removes the broken Show Steps / Hide Steps control.
- Keeps all planning data local in the browser.
