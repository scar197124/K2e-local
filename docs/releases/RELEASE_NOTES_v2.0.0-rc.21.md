# K2E Local v2.0.0-rc.21

## Compact Rates & Schedules polish

- Reduced oversized billing and time-of-use input fields.
- Uses a compact four-field control row on desktop, a 2x2 layout on smaller screens, and a single column on narrow phones.
- Added useful derived context instead of decorative empty space:
  - blended time-of-use rate,
  - modeled peak-period energy,
  - modeled off-peak energy.
- Kept the existing time-of-use cost estimate and deterministic calculation model.
- No changes to the locked guided home flow, Smart Home trust model, or AI Advisor foundation.
