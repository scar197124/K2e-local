# K2E Local v2.0.0-preview.5

## Simple Mode corrected

- Reduced the main journey from four steps to two: home details and estimate.
- Recommended household devices are added automatically.
- Moved device selection behind an optional **Adjust devices** control.
- Kept the electricity-rate fallback for people who do not know their rate.
- Removed the separate device-selection and review gates from the default path.

## Advanced Mode clarified

- Added separate Overview, Devices, Home & rate, and Results sections.
- Preserved shared household data between Simple and Advanced modes.
- Kept full wattage, runtime, quantity, duty-cycle, custom-device, export, and reset controls.
