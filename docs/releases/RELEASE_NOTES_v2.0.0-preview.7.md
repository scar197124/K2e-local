# K2E Local v2.0.0 Preview 7

## Clear Simple and Advanced separation

- Simple Mode remains a two-step household estimate.
- Advanced Mode now contains dedicated workspaces for detailed devices, smart-device planning, the AI Advisor, time-of-use rates and schedules, and reports.
- Household type, bedrooms, people, and base electricity rate remain a single shared source of truth.
- Added local smart thermostat, smart plug, and smart lighting planning estimates.
- Added a private local Advisor preview with an explicit disclosure that no connected AI service is active.
- Added a consent explanation for any future online AI connection.
- Added peak/off-peak rate modeling and report export.
