# K2E Local v2.0.0-rc.6

## Semantic Color Pass

This release adds a controlled visual color system to improve separation and scanability without changing the unified guided workflow.

### Changes

- Apartment uses a teal accent.
- Townhouse uses an amber accent.
- House uses a violet accent.
- Selected home cards retain strong text contrast and receive a matching selection indicator.
- Top energy users use five ranked accent colors rather than one repeated blue bar.
- Monthly energy and estimated cost use separate blue and green accents.
- The savings/action area uses a warm amber accent.
- Light-mode equivalents preserve readable contrast.
- No calculation, device, utility-import, workspace-height, or navigation behavior changed.

### Release metadata

- Version synchronized to v2.0.0-rc.6.
- Offline cache rotated to k2e-local-v2.0.0-rc.6.
