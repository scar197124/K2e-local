# K2E Local v2.0.0-rc.23

Release date: 2026-08-08

## What changed

- Aligned the public landing-page palette with the K2E Local application palette.
- Landing backgrounds now use the same deep navy family as the app.
- Primary accents now reuse K2E mint (`#68e0b4`) and energy blue (`#8bd3ff`).
- Amber (`#f6b84a`) is reused as a supporting energy/rate accent.
- Panel, text, muted-text, and border tones were brought into the same visual family.
- Existing landing-page structure, content, navigation, and responsive behavior were preserved.

## Scope

This is a visual consistency release. No energy calculations, household data behavior, Smart Home permissions, or AI Advisor logic were changed.
