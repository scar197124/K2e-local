# K2E Local v2.0.0-rc.40 — Seasonal Bill Forecasting

RC40 connects seasonal household pressure to Home Pulse, What-If Lab, Savings Missions, and the local AI Advisor.

## Added

- Summer, Winter, Spring/Fall, current-model, and custom climate-load forecast modes.
- Baseline bill, seasonal forecast, modeled delta, and climate-sensitive kWh.
- Transparent device-name detection for heating/cooling loads; non-climate devices are never seasonally adjusted.
- Home Pulse seasonal health strip.
- AI Advisor seasonal question.
- Seasonal check mission and top-climate-device handoff into What-If Lab.

## Safety / scope

This is a planning scenario, not a bill guarantee. It does not alter saved device values and does not call external utility or weather services.
