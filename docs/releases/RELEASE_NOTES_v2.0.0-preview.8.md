# K2E Local v2.0.0 Preview 8

## True mode separation
- Simple Mode remains a two-step household estimate.
- Advanced Mode is now a distinct full-control workspace.
- Both modes share one household and one calculation state.

## Advanced workspace
- Overview
- Detailed device controls
- Smart-home planning
- Local AI Advisor preview
- Rates and schedules
- Results and reports

## Layout stability
- Advanced cards now use fixed maximum heights.
- Device tables, advisor content, smart controls, rates, and reports scroll internally.
- Adding devices no longer makes the full page or card grow indefinitely.
