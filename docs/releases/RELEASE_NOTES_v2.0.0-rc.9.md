# K2E Local v2.0.0-rc.9

## Guided UI final polish

- Keeps the unified K2E guided experience and the rc.8 Insights information architecture unchanged.
- Tightens the spacing beneath the **View Insights** action without crowding the guided setup.
- Renames the first Insights emphasis to **Top household insight**, keeping the most household-specific observation first.
- Adds a clearer accessible name to the **View Insights** action.
- Adds reduced-motion support for users who request less animation or smooth scrolling.
- Improves **Start over** so utility-import messages, the utility importer, and the Add Device picker are reset along with household data.
- Keeps high-contrast essential text and the established professional accent-color system.
- No change to energy calculations, utility-rate parsing, device presets, or report math.
